# Bevor es losgeht

Schreibe eine kleine Webanwendung für eine interaktive To-Do-Liste.

- Zur Umsetzung sollen lediglich **HTML**, **CSS** (oder SCSS) sowie **JavaScript** zum Einsatz kommen
- Auf den Einsatz von weiteren Node Packages und Frameworks wie jQuery oder React soll verzichtet werden.

## Anforderungen

### 1. Aufgaben hinzufügen

- Über eine Schaltfläche soll es möglich sein, der Liste neue Aufgaben hinzuzufügen. Jede Aufgabe besteht aus einer kurzen Beschreibung
- Aufgaben sind standardmäßig nicht erledigt

### 3. Aufgaben als erledigt markieren

- Wenn der Benutzer auf die Checkbox einer Aufgabe klickt, soll der Status der Aufgabe auf “erledigt” oder “nicht erledigt” gesetzt werden (Toggle-Funktion)

### 4. Aufgaben löschen

- Der Benutzer soll durch Klick auf ein Papierkorb-Icon eine Aufgabe aus der Liste löschen können

### 5. Aufgaben filtern

- Es soll eine Möglichkeit geben, die Liste der Aufgaben zu filtern, sodass entweder nur alle Aufgaben, erledigte Aufgaben oder nicht erledigte Aufgaben angezeigt werden

#### _Bonus_

- Wird die Anwendung neu geladen, sollen alle bestehenden Aufgaben erhalten bleiben (auch wenn der Browser geschlossen wird)
- Implementiere eine Möglichkeit zur Bearbeitung einer bestehenden Aufgabe.
